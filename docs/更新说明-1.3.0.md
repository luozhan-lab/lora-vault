# 洛栈 · LoRA-Vault 1.3.0

## 这次改了什么

- **分类变成一棵树，还能自己管**：安装后自带七个顶层分类（角色 / 服装 / 画风 / 动作 / 场景 / 辅助 / 其他），每个下面能加子分类，比如「角色 → 原神」。侧栏点箭头展开、点名字筛选；管理弹窗里能新建、改名、删除、加子分类，删的时候会告诉你多少支会退回「未分类」。误删了内置分类，点「恢复默认」就能把七个顶层补回来。
- **多选批量改分类**：洛栈工具条点「选择」，勾一批卡片，选个分类点「改分类」就一起移过去；还能「全选本页」。
- **导入向导**：新装用户点「导入向导」，三步走完——选 LoRA 根目录（带自动检测）→ 扫描（读文件里的训练标签，分出触发词、特征词、服装词、身体词）→ 补 C 站信息（描述、预览图、页面词表，可跳过）。
- **下载会自动归类**：从 C站下载的 LoRA 按模型类型进对应分类——Character 进角色、Clothing 进服装、Style 进画风、Concept 进辅助、Poses 进动作、Scene 进场景。
- **会读页面描述里的词表**：很多作者写 `**Appearance** : …`、`**Default outfit** : …`、`**Best weight** : 1.0`，现在会拆出来填进触发词、特征词、服装词和权重；作者自起的套装名也会按词归类，道具和动作不会误进衣服里。
- **词性分得更准**：标签分类改用两万多条的大词表（服装、身体、头发、眼睛等），复合词按分词回退；`concept`、`nsfw`、`slider` 这类训练元标签不再被当成特征词拼进出图词。
- **修了一处桌面端的哑操作**：分类改名、工作流起名/改名原来走系统输入框，桌面端不弹窗、点了没反应；现在统一用站内输入框。
- **修了两处会让用户卡住的问题**：安装到非系统盘（D 盘等）报「跨卷无效」——安装器改成复制而不是移动；批量改完分类后选择状态没复位，再点一次会把旧记录又改一遍。

## 怎么升级

下载 `LoRA-Vault-1.3.0-setup.exe` 直接覆盖安装，数据和设置都保留。绿色版解压后替换整个文件夹，`%APPDATA%\LoRA-Vault` 里的数据不用动。

# LoRA-Vault 1.3.0

## What's new

- **Categories are a tree, and they're yours:** seven top-level categories ship with the app (character / outfit / style / action / scene / utility / other), each can hold sub-categories such as "character → Genshin". Click the arrow to expand, click the name to filter. Category management lets you create, rename, delete and nest; deleting tells you how many LoRAs fall back to "uncategorized". Deleted a built-in one by mistake? "Restore defaults" brings the seven back.
- **Bulk re-categorize:** hit "Select" in the library toolbar, tick a batch of cards, pick a category and move them all at once (or "select all on this page").
- **Import wizard:** three steps — pick your LoRA root (with auto-detect) → scan (reads training tags from each file and splits trigger / feature / outfit / body words) → optionally fill in Civitai info (description, preview, tag lists).
- **Downloads are auto-categorized** by Civitai model type: Character, Clothing, Style, Concept, Poses, Scene.
- **Reads tag lists from descriptions:** `**Appearance**: …`, `**Default outfit**: …`, `**Best weight**: 1.0` are parsed into trigger, feature, outfit words and weight; creator-made set names are classified per word, and props/actions stay out of the outfit box.
- **Sharper word classification:** a 20,000-entry vocabulary with a per-word fallback, and training meta tags (`concept`, `nsfw`, `slider`, …) are no longer treated as feature words.
- **Fixed a desktop dead click:** category rename and workflow naming used the system prompt, which Electron doesn't implement — nothing popped up. They now use an in-app input box.
- **Fixed two blockers:** installing to a non-system drive (D:, etc.) failed with "cross-volume move"; the installer now copies instead of moving. Bulk re-categorize also left the selection state behind and could re-apply old records.

## Upgrading

Run `LoRA-Vault-1.3.0-setup.exe` over your current install — data and settings are kept. Portable zip users: replace the whole folder; the data in `%APPDATA%\LoRA-Vault` stays as it is.

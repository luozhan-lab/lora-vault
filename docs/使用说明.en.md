# User manual

This manual covers three things: how to set it up the first time, what each page does, and where to look when generation stalls.

---

# First launch: three steps to your first image

## Step 1 — make sure ComfyUI is connected

Open Settings. Section A shows the ComfyUI status.

- "Connected" — skip this step
- "Not connected" — start ComfyUI yourself first; it turns green once it is up
- Want to launch it from here? Fill ComfyUI's install folder in section A and press Launch

**Nothing will generate until this passes.**

## Step 2 — check the folders

Still in Settings, scroll to section C:

- **LoRA folder**: where your `.safetensors` live. The library and every LoRA picker read from here
- **Model folder**: base models, CLIP, VAE
- **Output folder**: ComfyUI's output directory. The gallery and "Open output folder" both use it

A wrong folder doesn't error. It just shows nothing. If the library is empty, come back and check this.

## Step 3 — generate

1. Click Library on the left
2. Click a character card (Nahida, say). A gold border means it's selected
3. Click Create in the top right
4. The right panel fills in. When it's done it says "Done · seed …"

**Get the first one out, then start tuning.**

# Page map

| Page | What it's for |
|---|---|
| **Library** | Character library. Search, filter by work, previews, details and trigger words |
| **Models** | Base models / checkpoints / CLIP / VAE. Set defaults, copy names, delete files |
| **Create** | Pick six things: character, scene, outfit, pose, expression, people. Plus quick styles and extra words |
| **Expert** | Everything by hand: model, LoRA, prompts, weights, steps, CFG, seed, two-pass |
| **Records** | Search past prompts and see what was made and which LoRAs were attached |
| **Gallery** | Every image in the output folder and the samples folder. Search, sort, enlarge, multi-select delete |
| **Guide** | Beginner tutorial: what a model, a LoRA and a prompt actually are |
| **Settings** | ComfyUI, folders, content mode, updates, backups, about |

# Generating, step by step

## 1. Pick a person

Click a character card in the Library. For a random one, hit "Random character" on Create.

A gold border means selected; Create then uses that person.

## 2. Pick scene and clothes

On Create, section 02 has six slots: body, scene, outfit, people, pose, expression.

- Leaving one empty means random
- In a hurry? Use the quick style chips: Daily, Night, Swimsuit, Cafe, Rain…
- One chip fills all six slots at once

**Each slot opens a picker**: search, click a row to tick it, confirm bottom right.

## 3. Check the negative prompt

Scroll to Negative. A default list is already there (lowres, bad hands, extra fingers, watermark).

**Don't empty it.** Without it you get broken fingers and text artefacts.

## 4. Count

Pick 1–4 images, or "random N" (different settings each).

**Start with one**, check it, then batch.

## 5. Generate

Press "Generate" (or "Create") bottom right. The right panel shows progress.

When finished it reports "Done · seed 1234567". **Write that seed down** — reusing it keeps the person and framing stable.

## 6. When it's wrong

**Change one thing at a time.**

- Person right, background mush → move the scene word earlier or weight it: `(classroom:1.2)`
- Hands broken → add `bad hands`, `extra fingers` (already in the default negative)
- Face too pale → a light weight like `(blush:1.2)`
- Want a variation of the same image → "Same seed", change one word

## 7. Where the images are

The output folder is ComfyUI's output. Open **Gallery** inside the app, or "Open folder" for Explorer.

# Using the Expert page

Expert mode ignores the content-mode switch. What you type is what you get.

## Model

First field is the base model. After changing it, check whether CLIP/VAE followed; set them manually if not.

## LoRA

Character, outfit, style — each is a **click-to-open picker**:

1. Click the field
2. Type a name, file name or trigger word in the search box
3. Click a row; a ✓ appears
4. Press **OK** bottom right to apply. Cancel leaves it unchanged

The number under it is weight. **Start at 0.7**; add 0.05 if it doesn't look like her, subtract 0.05 if she turns stiff.

"+ Add a LoRA slot" attaches another one — **don't go past two**, they pollute each other.

## Prompts

Positive and negative are yours to write. Wrap lines freely; separate with commas.

## Parameters

- **Steps**: start at 28; 30–35 is finer but slower
- **CFG**: around 4. Higher smears, lower scatters
- **seed**: -1 is random. Reuse the previous number for the same image
- **Size**: portrait 832×1216, landscape 1216×832

## Two-pass (optional)

Tick "Pass 1 text→image → pass 2 image→image" to sketch first, then repaint with a second model.

Beginners: leave it off.

# Troubleshooting

## ComfyUI always says "not connected"

1. Confirm ComfyUI itself is running (open `127.0.0.1:8188` in a browser)
2. Check the address in Settings section A
3. Still stuck: Settings → Maintenance / API → "Health check" and read which item is red

## Nothing happens after pressing generate

Watch the status bottom left. Red means an error with a reason; yellow means queued. For errors: Settings → Maintenance → Open log.

## The person doesn't look like the character

Check in this order:

1. Is the LoRA weight too low (below 0.7 drifts)?
2. Are the LoRA and the base model the same family (an Anima LoRA on an SDXL model is effectively unused)?
3. Is the trigger word present and correct?
4. Try a different LoRA for the same character

## Hands and text keep breaking

The negative must contain: `bad hands, extra fingers, missing fingers, watermark, text`.

Avoid actions the model is bad at in the positive, like `holding hands`.

## The gallery is empty

The gallery reads two places: the **output folder** and the **samples folder**.

- Output empty: nothing generated recently, or the images were moved
- Samples: where curated images live

Switch the dropdown at the top to check.

## Updating

Settings → H "Update": paste the manifest URL and it checks once at startup. With a new version, press "Download & update"; it installs and restarts itself.

## Adult content switch

Off by default; only SFW output. To enable: Settings → 0 "Content mode" → read and accept the disclaimer → "Enable adult content".

Only then do the adult pools appear on Create. **Expert mode is not affected.**

## English UI

Click `EN` in the top right. Switch back with `中文`.

In English: character names, work titles and original LoRA names stay as they are, and the word bank shows the English tags — none of those need translating.

# One reminder

**Change one word at a time.**

Change ten and look once, and you never learn which one mattered. Change one and look once, and after ten rounds you know what every slot does.

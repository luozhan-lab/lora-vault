# 使用者手册

这份手册讲三件事：第一次怎么配起来、每个页面是干什么的、出图卡住时先查哪。

---

# 第一次打开：三步就能出图

## 第一步，确认连上 ComfyUI

打开「设置」，最上面 A 那栏写着 ComfyUI 状态。

- 显示「已连接」→ 跳过这一步
- 显示「未连接」→ 先自己启动 ComfyUI；它开着以后这里会自己变绿
- 想让它从这里启动：在 A 栏填 ComfyUI 的安装目录，点「启动」

**这一步没通过，后面都出不了图。**

## 第二步，看目录对不对

还是「设置」，往下到 C「目录」：

- **LoRA 目录**：你的 `.safetensors` 放的地方，洛栈和所有 LoRA 选择窗都从这里读
- **模型目录**：底模、CLIP、VAE 在哪
- **出图目录**：ComfyUI 的 output 目录。图库、「打开出图目录」都认这个

目录填错了不会报错，只会「什么都没有」。看到库是空的，先回来查这里。

## 第三步，出第一张图

1. 左边点「洛栈」
2. 点一张角色卡（比如纳西妲），卡片出现金边就是选中了
3. 右上角点「出图」
4. 右边那块会出图，出好了下面会写「出好了 · seed xxxxx」

**第一张出来以后，再慢慢调。**

# 页面地图

| 页面 | 干什么的 |
|---|---|
| **洛栈** | 角色库。搜名字、按作品筛、看预览图、点开看详情和触发词 |
| **模型** | 底模 / 整包 / CLIP / VAE。能设默认、复制名字、删文件 |
| **创作** | 按六项挑：角色、场景、服装、姿势、表情、人数。再加快速风格和附加词 |
| **专家** | 全手填：模型、LoRA、正负面词、权重、步数、CFG、seed、两段式 |
| **记录** | 按 prompt 里的词反查：以前出过什么、当时挂了哪几支 |
| **图库** | 出图目录和成品区的所有图。搜、排序、看大图、多选删除 |
| **教学** | 新手教程：模型/LoRA/提示词怎么理解，词怎么排 |
| **设置** | ComfyUI、目录、内容模式、更新、备份、关于 |

# 出图，一步一步来

## 1. 选人

「洛栈」里点一张角色卡。想随便来一张，就去「创作」点「随机角色」。

选中之后，卡片带金边，右上角「出图」就按这个人出。

## 2. 选场景和衣服

在「创作」页，02 那一栏六格：身体、场景、服装、人数、姿势、表情。

- 不选也行，不选就随机
- 想快点，直接点下面的「快速风格」：日常、夜景、泳装、咖啡、雨天……
- 风格一点，六格会一起被填好

**六格里的每一项，点开都是选择窗**：能搜、点一行勾选、右下角「确定」生效。

## 3. 看负面词

往下滚到「负面词」。默认已经有一串（低清、坏手、多手指、水印这些）。

**别一上手就删空。** 负面一空，手指和文字就出来了。

## 4. 张数

「张数」可以选 1 到 4，也能选「随机 N」（每张参数不同）。

**第一轮先出 1 张**，看对不对，再出多张。

## 5. 出图

右下角「一键出图」。右边那块会显示进度。

出完下面写「出好了 · seed 1234567」。**把这个 seed 记下来**——满意的话，下一轮填同一个 seed，人和构图才不会变。

## 6. 不满意怎么改

**一次只改一样。** 换机位、换表情、加减一个词，然后再出。

- 人对了、背景糊 → 把场景词往前挪，或给它加权重 `(classroom:1.2)`
- 手指崩 → 负面词里加 `bad hands`、`extra fingers`（默认就有）
- 脸色不对 → 加 `(blush:1.2)` 这种轻权重
- 想出同一张的重绘 → 「同 seed」再出，只改一个词

## 7. 图在哪

出图目录 = ComfyUI 的 output。软件里点「图库」就能看到，也可以点「打开目录」用资源管理器看。

# 专家页怎么用

专家页不跟着「内容模式」走，写了什么就是什么。

## 模型

第一格选底模。改完记得看下面 CLIP / VAE 有没有自动跟着变；不对就手动选。

## LoRA

角色、服装、画风，每个都是**点一下弹窗**：

1. 点那个框
2. 上面搜索框输名字、文件名或触发词
3. 列表里点一行，它前面会出现 ✓
4. 右下角「确定」才生效；「取消」不改

下面的数字是权重。**从 0.7 开始**，不像就加 0.05，僵了就减 0.05。

「＋ 加一个 LoRA 槽」可以再挂一支，但**别超过两支**，会互相污染。

## 词

正面词、负面词都自己写。第一行写不下可以换行，逗号分隔。

## 参数

- **步数**：28 起步，30 到 35 更细，但慢
- **CFG**：4 左右。太高会糊、太低会散
- **seed**：-1 是随机。想出同一张就填上次的数
- **尺寸**：竖图 832×1216，横图 1216×832

## 两段式（可选）

勾上「第一段出图 → 第二段图生图」，就是先出一张草样，再用第二段模型重画一遍。

新手先别开。

# 常见问题

## ComfyUI 一直「未连接」

1. 先确认 ComfyUI 自己启动了（浏览器能打开 `127.0.0.1:8188`）
2. 再看设置 A 栏里的地址对不对
3. 还不行：设置 → 维护 / 接口 → 「体检」，看它说哪一项红

## 出图点了没反应

看左下角状态。红色会写原因；黄色是还在排队。要是报错，设置 → 维护 → 打开日志。

## 出来的人不像角色

按顺序查：

1. 这支 LoRA 的权重是不是太低（0.7 以下容易跑）
2. LoRA 和底模是不是一个家族（Anima 的支挂 SDXL 底模基本等于白挂）
3. 触发词写了没有，写对没有
4. 换一支同角色的支试试

## 手指 / 文字总是崩

负面词里必须有：`bad hands, extra fingers, missing fingers, watermark, text`。

正面别写 `holding hands` 这种模型不擅长的动作。

## 图库是空的

图库有两个来源：**出图目录**和**成品区**。

- 出图目录空：说明最近没出图，或者图被搬走了
- 成品区：整理好的图都在这里

上面那个下拉框切一下就知道。

## 怎么更新

设置在 H「更新」：填更新清单地址，启动会自动查一次。有新版，点「下载并更新」，装完自己重启。

## 成人内容开关

默认关，只出正常图。要开：设置 → 0「内容模式」→ 打勾读协议 → 「开启成人内容」。

开完创作页的成人向词池才出现。**专家页不受这个开关影响。**

## 想用英文界面

右上角 `EN`。切回去点 `中文`。

英文界面里：角色名、作品名、LoRA 原名保持原样，词库显示英文 tag——这些本来就不用翻。

# 一句提醒

**一次只改一个词。**

改十样再看，你永远不知道是哪一样起了作用；改一样看一次，十次以后你就知道每个位置在干什么了。

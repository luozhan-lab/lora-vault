# 洛栈 · LoRA-Vault 1.3.2

## 这一版主要是优化出图区的流程

- **新增「落点」选项**：床、沙发、桌面、地板、靠墙、车座、台阶这些从「姿势」里单独拿出来选。姿势只管身体怎么摆，在哪儿由落点定；场景会限制可选落点。
- **姿势和动作重新整理**：姿势只写身体姿态，动作只写正在做什么，两边的选项都清了一遍，重复和混在一起的条目移掉了。
- **选项联动更一致**：道具会显示它的用法，手上动作和道具会互相检查；穿脱会按服装类型给对应的词，和姿势冲突时自动调整。
- **阶段选项细化**，单人和双人分开。
- **表情池扩充**，保持和场景、姿势、服装不联动，任何场合都能选任何表情。

## 选项池整理

场景 91、动作 64、姿势 40、双人日常 38、阶段双人 23 / 单人 10、落点 13、道具 64、手上 58、表情 60。

## 下载和资料

- C 站下载和补信息支持手填代理地址（设置 → Civitai 里有「代理地址」）；连不上时会直接告诉你需要挂代理，不再只丢一句请求失败。
- 描述词表解析支持「标签行、空一行、再写词表」的写法，触发词、特征词、服装词分得更准。

覆盖安装即可，数据和设置都保留。

# LoRA-Vault 1.3.2

## Mostly a workflow cleanup of the generation panel

- **New "Surface" option**: bed / sofa / desk / floor / wall / car seat / stairs are now chosen separately from the pose. The pose only says how the body is placed; the surface says where.
- **Poses and actions reorganized**: the pose list only contains postures, the action list only says what she is doing; duplicates and mixed entries were removed.
- **More consistent linking**: props show how they are used, hands and props check each other, undressing follows the outfit type and conflicts with the pose are adjusted automatically.
- **Stage options refined**, with separate sets for solo and duo.
- **Expression pool expanded**, still independent of scene, pose and outfit.

## Pools

Scenes 91, actions 64, poses 40, duo 38, stages 23 / 10, surfaces 13, props 64, hands 58, expressions 60.

## Download & metadata

- Civitai downloads accept a manual proxy address (Settings → Civitai). When the connection fails you get a clear "needs a proxy" message.
- Description parsing now handles the "label line, blank line, word list" layout, so trigger / appearance / outfit words are split more accurately.

Install over the current version — data and settings are kept.

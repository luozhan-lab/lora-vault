# 开发日志

洛栈 · LoRA-Vault 的开发记录。按时间排，写的是「当时为什么这么改」和「踩了什么坑」，不是提交列表。

- 当前版本：**1.0.0**
- 环境：Electron + 本地 Node 后端（`server.mjs`，端口 8787）+ SQLite（`lora.db`）
- 界面：`public/v2/`（`index.html` + `app.js` + `app.css`），无框架
- 日志正文在 `DEVLOG.md`（约 900 行，技术流水）；这份是给人读的版本

## 一期：从旧界面到 v2（凌晨）

起点是一个能跑但界面凑合的版本：高级页能填参数，简单模式只有几个格子。

### 为什么要重写

旧界面能出图，但三件事做不到：

1. 库和出图是割裂的——在库里看见一支，去出图要重新找一遍
2. 参数全摊在一页上，新手看不懂，老手嫌乱
3. 没有预览图的位置，不知道自己在选什么

于是另起 `public/v2/`，边上新页边把旧页的功能一件件搬过去，搬完就下线旧页。

### v2 的第一批页面

- **洛栈（库）**：分类 / 作品 / 标签三层筛选，卡片网格，搜索
- **创作**：六项随机——人、在干什么、穿什么、在哪儿、怎么拍、什么气氛
- **模型**：底模、整包、CLIP、VAE，能设默认
- **记录**：按 prompt 反查历史
- **设置**：ComfyUI 地址、目录、扫描

夜里 04:50 到 05:40 之间把库、下载、六项、ComfyUI 冷启动、生成取消、预览图这几条主链路跑通，然后旧页下线。

### 早期踩的三个坑

| 坑 | 根因 | 修法 |
|---|---|---|
| ComfyUI 认不出安装目录 | Comfy Desktop 2 的 `settings.json` 只记父目录，真实路径在 `installations.json` 的 `installPath` | 读 `installations.json`，兼容 `…\ComfyUI\main.py` 这种嵌套；启动命令固定用安装目录里的 `.venv\Scripts\python.exe`，不依赖 PATH |
| 取消出图后记录里留一条 `error` | `cancelRequested` 被当成异常写进 job | 取消分支直接置 `cancelled`；出图前加 `precheck`（模型 / CLIP / VAE / 各槽 LoRA / 词 / 目录一次查完），不通就不交任务 |
| 进度条多张时来回跳 | 进度按全局计数，不分第几张 | 状态条改成 `正在出图… x/y · 第 1/N 张 · 第一段/第二段`，数据取 job 的 `done/total` |

## 二期：出图体验（上午）

这一段几乎全是「用了两天之后发现不对」的修补，按用户反馈顺序排。

### 结果要能回看

出过的图原本只活在当前会话里，刷新就没了。加了结果历史表：prompt、seed、模型、LoRA、出图路径、时间，全部落库。

**顺带**修了「两段式 + 4 张批量」的进度错乱：进度条按全局计数，多张时会跳回 0。

### 角色栏改版

原来角色是一排小方块，选完看不出是谁。改成卡片：预览图 + 中文名 + 最近使用标记。

**规则定死**：没有预览图的角色，卡片上放占位色块 + 名字首字，不空着。

### 双人与动作分池

「双人」这个选项一开，动作池就该换一套（单人动作双人做不出来）。做成两个池子：按人数过滤，选了两人就不再给单人动作。

**顺手做的**：第二角色 LoRA 槽、服装支槽、辅助支槽。

### 服装「原装」和穿脱

角色支自带原设衣服。想要「角色 + 别人的衣服」，就得允许关掉原装。

做成一个开关：`覆盖角色体型` / `服装 = 原装`。选了原装就不额外挂服装支。

### 幼女 / 萝莉 / 少女 / 女青年 / 成女

五档体型分开列，不合并。这一条后来反复出问题（见三期）。

### 中文名与翻译

LoRA 文件名多是英文 + 日文，看不出是谁。加了自动翻译：取文件名里的角色名，翻成中文写进 `name_zh`。

**踩坑**：机器翻译会把 `arm up` 翻成「武装起来」、`looking back` 翻成「回看之下」。所以现在翻译只作为候选，详情页有个「译名」按钮手动确认。

### 模型家族

Anima / SDXL / Illustrious 三套的 CLIP/VAE 不一样。挂错家族不会报错，只会「LoRA 不生效」。

做了三件事：

1. 换模型时自动带出配套的 CLIP/VAE
2. 按底模家族过滤 LoRA 列表
3. 「体检」里列出对不上的 LoRA

## 三期：发布与打磨（下午）

### 正式命名

从「洛栈」定名到 **洛栈 · LoRA-Vault**，图标重做（琥珀底 + 深色 L 字徽）。

图标第一版是三块暖色圆角叠起来，缩到 16px 像一坨。换成琥珀色底板 + 深色字母，16/24/32 都还能认。

### 专家模式独立成页

高级面板原本缩在创作页下面，老手用起来别扭。拆成独立页：模型、CLIP/VAE、三个 LoRA 槽 + 动态槽、正面/负面词、步数/CFG/seed/尺寸/采样器、两段式。

**专家页不受内容开关限制**——它自己写词，跟着开关走没有意义。

### 工作流导入

支持把 ComfyUI 的 `Save (API)` JSON 导进来，占位符替换：`{{prompt}} {{negative}} {{seed}} {{steps}} {{cfg}} {{width}} {{height}} {{sampler}} {{scheduler}} {{model}} {{clip}} {{vae}}`。

导入能保存、改名、删除，列表在设置里管。

### 安装器

自写一个 WinForms 安装器（`scripts/build-installer.mjs`）：把整个应用嵌进 exe，运行后解到 `%LOCALAPPDATA%\Programs\LoraLibrary`，改快捷方式、写注册表。

**坑一**：安装器在 `%TEMP%` 里跑，清理时把自己删了——改成先 `SetCurrentDirectory(%TEMP%)` 再删。
**坑二**：安装目录里跑 updater 会导致目录删不掉（文件占用）——把进程杀掉、cwd 挪出来、三次重试后再改名 `.old-*`。

### 自动更新

`/api/update/check` → `/status` → `/download` → `/install` 四个接口：查清单、下载（校验 sha256 和 PE 头）、静默安装、自动重启。

端到端跑通过两次，包括静默安装后快捷方式和注册表重写。

## 四期：内容模式、词表、图库、多语言（傍晚）

### 内容模式

成人内容池默认关闭，只出正常图。开启要走一次免责协议（六条：年龄 / 虚构 / 责任 / 用途 / 数据 / 可关闭）。

设成「设置页 0 号面板」，默认关；开关和提示都写清楚「关掉只出正常图」「专家模式不受影响」。

### 内置词表

从 `lora.db` 里统计「被多少支 LoRA 用过」，取前 20000 个 tag，导出 `public/v2/wordbank.json`。

- 分类按关键词硬判（头发 / 眼睛 / 服装 / 姿势 / 表情 / 构图 / 光 / 质量 / 其他）
- 中文名人工核了 260 条，其余留空，不硬翻
- 创作页和专家页都能打开词表：搜索、分类筛、点一行插到正面（Shift 插到负面）

**为什么不抄网上通用表**：Danbooru 有几百万个 tag，抄下来一半没人用；用自己库里的数据，排出来的顺序就是「这支 LoRA 实际被怎么用」。

### 教学页

新手教学写在 `docs/新手教学.md`，`build-guide.mjs` 转成 `guide.html` 注入页面。

内容按「上手之前 → 正面词怎么写 → 权重 → LoRA 配比 → 完整流程 → 常见错误 → 怎么练」排，不堆术语。

### 图库

`/api/gallery` 原本只列顶层文件、只能删单文件名。改成：

- 递归最多 3 层（成品区按作品分文件夹）
- 两个根可选：出图目录 / 成品区（成品区现在是 779 张）
- 返回相对路径，删除按相对路径校验（拒 `..`、拒越界）
- 界面：搜索、排序、点开看大图、多选删除

**发现的情况**：出图目录经常是空的（成品被搬去成品区了），所以空态会提示切到「成品区」。

### 英文界面

原则定下来：**只翻界面，不翻数据。**

- 角色名、作品名、LoRA 原名保持原样
- 词库标签在英文界面直接显示英文 tag（`bedroom` 而不是「卧室」）
- LoRA 显示名走 `loraLabel()`：中文取 `name_zh`，英文取原名
- 教学和使用说明各出一份英文 md，一起构建

`i18n.js` 的 EN 表从 444 条补到约 900 条，新面板全在。带数字的句子在 JS 里按语言分支，不硬塞词表。

### 关于页

免费使用说明 + 两个链接：

- 「支持作者」→ 爱发电
- 「作品展示」→ C 站主页

链接放 `data/config.json`（`sponsorUrl` / `portfolioUrl`），留空则整块不显示；只接受 `http(s)`；点击走系统浏览器，不在应用里开网页。

界面里不出现「付费 / 解锁 / 会员 / 购买」，不做浮动求赞助条。

### 使用说明

`docs/使用说明.md`，7 节：第一次三步、页面地图、出图流程、专家页、常见问题、一句提醒。

洛栈页顶部有一张首次提示卡（`localStorage v2-firstrun-done` 控制，只出现一次），点开直接跳说明页。

`build-guide.mjs` 为此补了**有序列表**和**表格**支持。

## 这一版修掉的 bug

按「症状 → 根因 → 修法」记，方便以后对照。

### 1. 专家页底部「出图」按钮被截

- **症状**：滚到底，按钮只露一半，再滚不动
- **根因**：`.shell` 高度写成 `calc(100vh - 40px)`，而 40px 已经是 `padding-top`；`.main` 又用 `height:100%` 解析成 971px，起点在 144 → 下沿 1115，`body` 是 `overflow:hidden`，多出来的 104px 直接被裁掉
- **修法**：改成 `100vh` + `.workspace` 纵向 flex（`min-height:0`）+ `.main { flex:1; height:auto }`

### 2. 教学页列表和分隔线不渲染

- **症状**：md 里写了 `-` 和 `---`，页面上是一坨文字
- **根因**：转换器只认标题、段落、代码块
- **修法**：补 `<ul>` / `<ol>` / `<hr>` / `<table>` 四类

### 3. 词表搜中文搜不到

- **症状**：输「从下往上」找不到 `from below`
- **根因**：内置词表把中文名覆盖成「仰视」，搜索只查一个标签
- **修法**：词条加 `alt` 别名，中英文都进匹配

### 4. `package.json` 带 BOM，release 脚本崩

- **症状**：`JSON.parse` 报 unexpected token
- **根因**：文件头有 U+FEFF
- **修法**：所有读 JSON 的地方统一 `replace(/^\uFEFF/, '')`

### 5. 安装器把自己杀了

- **症状**：自动更新跑到一半，安装器进程消失
- **根因**：`taskkill /T` 顺带把子进程（安装器）一起杀了
- **修法**：去掉 `/T`，后端 node 按路径精确杀

### 6. 安装目录删不掉

- **症状**：更新后目录残留，下次装冲突
- **根因**：安装器 cwd 在安装目录里，占着句柄
- **修法**：cwd 挪到 `%TEMP%`，删除重试三次，失败改名 `.old-*`

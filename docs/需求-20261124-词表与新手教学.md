## 一、词表功能

### 数据从哪来

**不要从网上下载通用标签表。** Danbooru 有几百万个标签，抄下来的表是死的，一半的词根本没人用。

用我们自己库里的真实数据。位置：

```
lora-library\data\lora.db
```

相关两张表：

- `tag(id INTEGER, name TEXT, kind TEXT)` —— 现有 29941 个标签
- `lora_tag(lora_id, tag_id, count)` —— 现有 270699 条关联

`kind` 是分类，值里出现过「作品」「角色」等中文。

### 怎么筛

按「被多少支 LoRA 用过」排序，取前 20000 个：

```sql
SELECT t.name, COUNT(*) c
FROM lora_tag lt JOIN tag t ON t.id = lt.tag_id
GROUP BY t.name
ORDER BY c DESC
LIMIT 20000;
```

### 存储建议

导出一份 JSON，放 `public/v2/wordbank.json`：

```json
[
  { "word": "long hair", "cn": "长发", "cat": "hair", "count": 515 },
  { "word": "looking at viewer", "cn": "看向镜头", "cat": "composition", "count": 631 }
]
```

`cat` 建议这几类：`hair` `eyes` `body` `clothes` `expression` `action` `pose` `composition` `scene` `light` `quality` `other`。

分类先按关键词表硬判（头发相关进 `hair`，`from *` 进 `composition`，`looking *` 进 `expression`），剩下的进 `other`。**不用一次分完。**

### 界面要求

- 搜索框，中文和英文都能搜（`长发` 和 `long hair` 都命中）
- 按 `count` 从高到低排，常用的在上面
- 每条旁边一个「插入」按钮，点了追加到当前提示词框末尾
- 分类可筛，默认不筛，先给搜索
- 全部本地，不联网

### 中文释义

20000 条一次翻完不现实。建议：先翻前 2000 条（覆盖实际使用的大半），剩下 18000 条只显示英文，翻译留空；翻过的写回 JSON，下次启动直接读，不重复翻。复用 `lib/translate.mjs`。

# 上手之前，先弄清楚这几样东西

## 模型是什么

模型是一个几 GB 的文件。里面装的不是代码，是「看过几百万张画之后，学会怎么画」的那点本事。

它不会思考，也不懂你在说什么。它做的事只有一件：**接着往下画**。

你给它一段话，它就画一张尽量符合这段话的画。你写得含糊，它就自己编——编得好是运气，编得差是常态。

模型决定画风和画功。同一个人、同一句话，换一个模型，出来就像换了画师。

## LoRA 是什么

LoRA 是一个小文件，几十到几百 MB，专门补一节课用。

模型本身不认识「缇宝」是谁、不认识「某个特定画风」。挂上对应的 LoRA，它才认识。

所以 LoRA 干的事，是**给通用画师补一门专业课**：这一张脸怎么画、这个发型怎么画、这件衣服怎么画。

LoRA 不能单独用，必须挂在模型上。

还有一个新手最容易踩的坑：**LoRA 和模型是配套的。** A 系列的 LoRA 挂到 B 系列的模型上，多数情况下是白挂——不报错、图照样出，但 LoRA 根本没起作用，画出来还是模型自己瞎编的样子。

（我们软件里的「体检」会看这个。看到「对不上的 LoRA」就换一支。）

## 提示词是什么

提示词分成两栏：**正面词**和**负面词**。

**正面词写你要什么。**

```
1girl, white shirt, black skirt, classroom, full body
```

**负面词写你不要什么。**

```
lowres, bad hands, extra fingers, watermark
```

一句话记住区别：正面词是菜单，负面词是忌口。

## 为什么一定要写负面词

因为模型不知道什么叫做「画坏了」。

它没长手，也没见过真实的手指有几节。它只知道「概率上这里该有一根线」，所以画出一只手六根手指，它不觉得有问题。

负面词的作用是：**提前告诉它哪些地方容易出事，让它往小心那边偏。**

你不写 `bad hands`，它就不在乎手；你写了，它在画手的时候会格外谨慎。

还有第二个作用：**你不写的地方，它会自己填。**

只写「一个人」，不写背景，它可能给你一片白，也可能给你一片森林。你不想让它乱填的，就得自己写清楚。

新手先用这一套负面词，能救掉一半废图：

```
lowres, worst quality, bad anatomy, bad hands, bad feet,
extra fingers, missing fingers, watermark, text, signature
```

**别一上来抄两百个。** 负面压太狠，画面会变平、颜色发灰、人也发僵。

# 正面词怎么写

## 词的顺序，就是重要程度

一行提示词从左往右读。越靠前，模型越当回事。

推荐的顺序：

```
谁 → 在干什么 → 穿什么 → 在哪儿 → 怎么拍 → 光 → 画质
```

不是必须凑齐，是缺了哪一样，模型就自己补哪一样。

## 一、先说清楚画谁

第一句先说画面里有几个人。

`1girl` 一个女孩，`2girls` 两个，`1boy` 一个男孩。不写数量，模型可能给你画三个。

然后是这个人本身：头发、眼睛、身材。

```
long hair, black hair, blue eyes, twintails
```

有一个词要单独说：`solo`。它的意思是「画面里只有这一个人」。不加，模型经常在旁边塞个路人，或者把手伸进画面。

## 二、在干什么

这是新手最容易漏、也最影响成片的一样。

```
standing      站
sitting       坐
lying on bed  躺床上
kneeling      跪
leaning       靠
walking       走
```

**同一个角色，同一身衣服，只换这一句，观感差很远。**

只写 `standing`，出来的是一张立绘——人站着，背景虚虚的，像证件照。

写成 `standing by the window, looking back`，出来的是一张画——有动作、有方向、有故事。

前者是「这个角色长什么样」，后者是「这个人正在做什么」。你想画哪一种，自己定。

## 三、穿什么

衣服要一件一件说，并且上下分开。

```
white shirt, black skirt, thighhighs, brown shoes
```

只写「校服」，模型给你泳装都有可能——它只知道"校服"大概是个学校的东西。

## 四、在哪儿

先定大方向：`indoors` 室内、`outdoors` 室外。

再往下：

```
classroom   教室
bedroom     卧室
beach       海边
forest      森林
street      街道
```

**场景词三个就够。** 写十个，模型反而不知道你想在哪儿，最后给你一片糊。

## 五、怎么拍

这一组叫机位，它决定「这张是立绘还是照片」。

```
full body     全身
upper body    上半身
cowboy shot   大腿以上
portrait      只拍脸
from behind   从背后拍
from side     侧面
from above    从上往下
from below    从下往上
```

还是那套衣服那个动作，只换这一句：

- `full body` → 平和，看清楚人，但没什么气势
- `from below` → 从下往上看，人显得高、有压迫感
- `from above` → 从上往下看，人显得小、弱势
- `from behind` → 看不见脸，靠背影和姿态说话

**新手如果只学一样东西，学这个。** 换机位比换衣服管用得多。

## 六、光

```
backlight       逆光，人镶一圈边
moonlight       月光，冷
soft lighting   柔光，脸干净
dramatic light  硬光，对比强
```

光这一层，是「能看」和「好看」之间的那道门。同一张图，加个 `backlight`，立刻就不一样了。

新手先记住一条：**光要有方向**。写 `light from the window`（光从窗户来）比写 `good lighting` 有用一百倍。

## 七、画质词

```
masterpiece, best quality, highly detailed
```

这三个词现在被模型普遍认，加了确实会精致一点。

但别指望它们救一张构图就错的图。**画质词是装饰，不是基础。**

# 权重怎么加

写法是 `(词:数字)`。数字大于 1 是加强，小于 1 是减弱。

```
(blush:1.2)      脸红更明显
(smile:0.8)      笑得淡一点
```

## 什么时候该加

- 想要的东西出不来（比如写了 `blush` 但脸不红）→ 加到 1.2 到 1.3
- 不想要的东西压不住（比如一直画成大胸）→ 反面压，或者负面词里加
- 两个词打架（比如同时写 `smile` 和 `sad`）→ 挑一个，另一个删掉

## 加多少

**一般 1.1 到 1.3 就够了。超过 1.5 基本都会坏。**

新手最常见的毛病是一激动全写 1.5、2.0。加过头会把画面烧糊：头发和脸粘成一团、颜色发焦、线条发硬。

## 加不上去怎么办

如果加到 1.4 那个词还是不出来，说明**不是权重问题**，是模型根本不知道那个词，或者那个词跟别的词冲突了。

这时候加权重没用，得换词、或者删掉冲突的词。

# LoRA 怎么配

## 挂在哪

挂在你选好的模型上。一支角色 LoRA + 一个底模，这是最基本的一组。

## 权重给多少

LoRA 的权重跟提示词权重是两回事，但写法一样。

- **0.6 到 0.8** 是常用范围，角色还原和模型画风的平衡点
- **低了（0.5 以下）** 角色不像，会往模型自己的画风上跑
- **高了（0.9 以上）** 角色像了，但人也僵了，背景也塌了——因为 LoRA 学的时候素材多是站姿特写，它不知道背景怎么画

新手从 **0.7** 开始，觉得不像就往上加 0.05，觉得僵就往下减 0.05。

## 不要挂太多

一支角色 + 一支服装，这是新手能稳住的上限。

三支以上叠在一起，颜色会互相污染（月光 + 红色角色 → 角色变成紫的），手脚也容易糊。

**一次只挂一支，先把人物出对。** 出对了再考虑加别的。

## 别让 LoRA 互相打架

两支 LoRA 都在改同一块地方（比如都是改脸），就会互相打架，结果是两张脸糊在一起。

如果非要同时挂两支，把不重要的那支压低（0.4 到 0.5）。

# 完整的一次，从头到尾

假设要画：一个黑长发少女，白衬衫黑裙子，站在傍晚的教室里，全身。

**第一步，选模型。** 选一个二次元风格的底模。

**第二步，挂角色 LoRA。** 权重 0.7。

**第三步，写正面词。**

```
1girl, solo, long black hair, blue eyes,
white shirt, black skirt, thighhighs,
standing, classroom, sunset, long shadows,
full body, backlight
```

数一下，十八个词。这就是新手该有的长度。

**第四步，写负面词。**

```
lowres, worst quality, bad anatomy, bad hands, bad feet,
extra fingers, missing fingers, watermark, text, signature
```

**第五步，出图。** 看哪里不对。

假设出来的问题：脸不错，但背景糊成一片，看不出是教室。

**第六步，改一处。**

把 `classroom` 提到更前面，或者加成 `(classroom:1.2)`。

**只改这一处，重跑。** 看差别。

如果好了，说明是权重问题；如果没变，说明模型对这个词的响应就是弱，得换成更具体的词，比如 `desks, chalkboard, classroom`。

**这就是整个流程。一次改一处，改完看差别。**

# 三个新手最常犯的错

## 一、词太多

写了六十个词，出来的图什么都不像。

模型的注意力是有限的，词越多，每个词分到的越少。二十个词以内是新手比较舒服的范围。

**宁可少写十个词，也不要多写十个没用的。**

## 二、同一个意思写两遍

`smile, happy, grinning` 写在一起，模型会以为你要一张笑到崩的脸。

`long hair, very long hair, floor length hair` 三连，头发会长到拖地。

**选一个最准的就行。**

## 三、不知道怎么改

图不对，不要整行重写。整行重写，你不知道是哪一句起了作用。

**一次只改一处。** 改完立刻看差别。这样十次之后，你就知道每个词在干什么了。

# 怎么练

别一上来就追求完美。

**第一轮，只写十二个词。**

```
1girl, solo, standing, white shirt, black skirt, classroom, full body
```

跑一张，看它给你画成什么样。

**第二轮，加表情。** 加一个 `smile`，看脸变了没有。

**第三轮，换机位。** 把 `full body` 换成 `from below`，看气势变了没有。

**第四轮，加光。** 加 `backlight` 或 `moonlight`，看氛围变了没有。

**第五轮，挂 LoRA。** 选一个角色，权重 0.7，看是不是变成那个人了。

五轮走下来，你就知道每个位置上的词在干什么了。以后再看到别人的图，也能大致猜出他是怎么写的。

词是工具，不是咒语。

你写得越像在跟一个人说「我想看这样一格」，它画得越对。

## 三、关于页与赞助链接

### 位置

设置页最下面，或者单独一个「关于」页。**不要弹窗，不要首次启动时出现，不要挡在任何功能前面。**

### 硬规则

- 全部功能免费，赞助与否完全一样
- 赞助不加任何特权：不解锁功能、不去水印、不给优先
- 软件里不出现「付费」「解锁」「会员」「购买」这类字
- 不弹「请支持我们」的悬浮条

### 文案

```
洛栈 · LoRA-Vault
版本 1.0.0

免费使用。全部功能都不需要赞助，
赞助也不会换来任何额外的功能。

如果它帮上你了，可以请作者喝杯咖啡：

  [ 支持作者 ]

你的库、预览图和配置全部在本机，不会上传。
```

那句「赞助也不会换来任何额外的功能」要留着。它让这件事的性质从「交易」变成「打赏」，也让人知道不用为功能付钱。

### 链接怎么处理

- 用 `shell.openExternal` 在系统浏览器里打开，不在软件内嵌网页
- 链接指向一个中立的页面（C 站主页、Ko-fi 或单独的 PayPal.me 页），**不要直接链到 PayPal 收款页并写着软件名**
- 链接配置放在 `data/config.json` 里，方便以后换

### 不放的地方

- 启动画面
- 出图完成后的结果页
- 任何报错提示旁边
- 成人内容开关附近

这几处一放，观感就从「支持作者」变成「催钱」了。

## 三之二、爱发电页面怎么写

### 身份定成什么

**训练师。** 不是「软件作者」，也不是「AI 画师」。

这个身份是真的：一直在训 LoRA，有成品在 C 站，有流程有参数。审核看什么都不怕，因为写的都是真的。

### 页面结构

**一句话介绍**

> 训 LoRA 的。二次元角色为主，熟 Anima 系底模，接受委托。

**我能做什么**

三块，按接单量排：

- 角色 LoRA 训练：给参考图，训一支认得住的角色
- 风格 LoRA 训练：拿一批同画风的图，训一种风格
- 服装 / 道具 LoRA：单独的衣装或配件

**价格**

2026 年 11 月调研的市场区间，供参考：

- 帮人训一支：30 元（素材现成、简单角色）到 500 元（多角度、复杂设定、含修改）
- 中间档：100 元左右是主流报价
- 成品月费：5 到 80 元一档，看内容量

**流程写清楚，比价格更重要**

素材怎么给 → 训多久 → 出几张验图 → 不满意怎么改 → 交付什么文件。写清楚了，问价的人少一半，接了也不容易扯皮。

**作品展示**

C 站上已经发的那几支，直接贴链接。这是最硬的东西——不用说自己行，图在那儿。

### 不要出现的词

- 「AI 出图」「出图软件」——一写就把性质从训练师变成工具作者
- 任何成人向相关字样
- 「无限制」「什么都能画」这类承诺

软件这个东西，在爱发电那边只能是「我自己写了个管理工具，顺手公开了」这种语气，一句话带过。主角是训练。

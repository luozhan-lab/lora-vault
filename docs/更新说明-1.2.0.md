# 洛栈 · LoRA-Vault 1.2.0

## 这次改了什么

- **分类可以自己管了**：装完自带七个顶层分类（角色 / 服装 / 画风 / 动作 / 场景 / 辅助 / 其他），每个分类下面能加子分类，比如「角色 → 原神」。分类侧栏换成树，点箭头展开、点名字筛选；分类管理里能新建、改名、删除，删的时候会告诉你里面有多少支会退回「未分类」，文件不动。
- **旧库自动迁移**：第一次启动会把原来的「分类 + 作品」迁成树（`角色/原神` 这种），`辅助Lora` 并进辅助、`AI娘` 并进角色。
- **下载自动归类**：从 C站下载的 LoRA 按模型类型直接进对应分类——Character 进角色、Clothing 进服装、Style 进画风、Concept 进辅助、Poses 进动作、Scene 进场景。
- **会读 C站页面里的词表**：很多作者在描述里写 `**Appearance** : …`、`**Default outfit** : …`、`**Best weight** : 1.0`，现在会把这些拆出来填进触发词、特征词、服装词和权重；作者自己起的套装名（如「Operation Yum 2025」）也会按词逐个归类，道具和动作不会误塞进衣服里。
- **词性分得更准**：标签分类改用两万多条的大词表（服装、身体、头发、眼睛、兽耳等），复合词按分词回退，道具（剑、书）不再混进人物属性；触发词最多收 5 个。
- **小修**：纹身的「淫纹」从位置挪到图案里；合并了「淋浴 / 浴场」两组太像的场景；成人动作池里的道具和身体状态词清掉；额外服装里和主题套装重复的删掉。
- **数据目录改成英文路径**：`%APPDATA%\LoRA-Vault`（原来 `%APPDATA%\LoRA 库`），第一次启动自动把老数据复制过去，老目录保留。

## 怎么升级

下载 `LoRA-Vault-1.2.0-setup.exe` 直接覆盖安装，数据和设置都保留。绿色版解压后替换整个文件夹，`%APPDATA%\LoRA-Vault` 里的数据不用动。

# LoRA-Vault 1.2.0

## What's new

- **Categories are yours to manage now.** Seven top-level categories ship with the app (character / outfit / style / action / scene / utility / other), and each can have sub-categories — e.g. "character → Genshin". The library sidebar is a tree: click the arrow to expand, click the name to filter. Category management lets you create, rename and delete; deleting tells you how many LoRAs fall back to "uncategorized", and never touches files.
- **Old libraries migrate automatically.** On first launch the old "category + work" pairs are turned into a tree (`character/Genshin`), with `辅助Lora` folded into utility and `AI娘` into character.
- **Downloads are auto-categorized.** Models pulled from Civitai go straight into the matching category by model type — Character, Clothing, Style, Concept, Poses, Scene.
- **Reads tag lists from Civitai descriptions.** Many creators write `**Appearance**: …`, `**Default outfit**: …`, `**Best weight**: 1.0` in the description; those are now parsed into trigger, feature, outfit words and weight. Creator-made set names (like "Operation Yum 2025") are split per word and classified, while props and actions are kept out of the outfit box.
- **Sharper word classification.** Tag classification now uses a 20,000-entry vocabulary (outfits, body, hair, eyes, animal ears), with a per-word fallback for compound phrases; props (swords, books) no longer leak into character attributes; up to five trigger words are kept.
- **Small fixes:** "womb tattoo" moved from position to pattern; merged the too-similar "shower / bath house" scenes; cleaned props and body-state words out of the adult action pool; removed duplicate outfits from the extra-outfit pool.
- **Data folder moved to an English path:** `%APPDATA%\LoRA-Vault` (previously `%APPDATA%\LoRA 库`). Your old data is copied over on first launch and the old folder is kept.

## Upgrading

Run `LoRA-Vault-1.2.0-setup.exe` over your current install — data and settings are kept. Portable zip users: replace the whole folder; the data in `%APPDATA%\LoRA-Vault` stays as it is.

## 二、接下来：中文名

### 怎么分批

| 区间 | 谁做 | 为什么 |
|---|---|---|
| 1–800 | **已完成** | 高频，机器翻不准 |
| 801–3000 | 机器翻，翻完人工抽查 | 开始出现大量名词，机器够用；但仍有歧义词混着 |
| 3001–20000 | 机器翻，不用抽查 | 长尾词，多是 `xxx dress` `xxx shoes` 这种组合 |

### 什么词机器一定会翻错

判断办法就一条：**这个词是不是「动词 + 介词」或者有画面歧义。**

- `arm up` → 机器会翻成「武装起来」，应该是「抬手」
- `looking back` → 「回看之下」，应该是「回头看」
- `holding sword` → 「举行剑」，应该是「持剑」
- `out of frame` → 「框架外」，应该是「出画」

这三种都集中在前 800，已经手工处理掉了。往后剩下的多是名词组合，风险低。

### 硬性要求

1. **不要覆盖已有 `cn`**。写回前先判 `if (x.cn) continue`
2. 翻不出来的（`paizuri`、`underboob` 这种）**留空，不要强行造词**。空着比错着好
3. 写回前先 `json.load` 一次，确认 20000 条、`cn` 非空是 800 条 —— 对不上就说明有人同时改过，停下来问

## 三、更要紧的：分类细化

### 为什么这件事比中文更急

`other` 装了一万四千多条，占 72.8%。用户点「服装」只出 2559 条，剩下的全挤在「其他」——**分类筛选基本是废的**。

中文看不懂还能猜（`long hair` 谁都知道是长发），分类点进去一半在「其他」是真难受。

### 建议的分类规则

按词根匹配，先到先得，一套顺序判下来：

```
1. composition   ← from *, looking *, shot, -view, close-up, portrait,
                    full body, upper body, dutch angle, letterboxed, border
2. quality       ← masterpiece, best quality, highres, detailed, realistic,
                    monochrome, greyscale, sketch, anime coloring
3. light         ← light, lighting, shadow, backlight, sunlight, moonlight,
                    flare, glow, sparkle, particles
4. hair          ← hair, bangs, ponytail, twintails, braid, bun, ahoge,
                    sidelocks, hairband, hair intakes, gradient hair
5. eyes          ← eyes, pupils, eyelashes, eyebrows, eyelid
6. expression    ← smile, blush, crying, tears, frown, pout, embarrassed,
                    expressionless, blush, sweatdrops, anger vein
7. clothes       ← shirt, skirt, dress, jacket, coat, hat, shoes, boots,
                    socks, gloves, uniform, swimsuit, bikini, bra, panties,
                    leotard, armor, apron, scarf, ribbon, collar, sleeve,
                    tie, belt, headwear, footwear, legwear, lingerie
8. body          ← breasts, thighs, legs, hips, waist, abs, navel, shoulder,
                    skin, muscle, chest, butt, ass, areola, nipple
9. pose          ← standing, sitting, kneeling, lying, on stomach, on back,
                    all fours, seiza, straddling, on one knee, squating
10. action       ← holding, pointing, waving, reaching, undressing, eating,
                    drinking, walking, running, sleeping
11. scene        ← indoors, outdoors, sky, room, classroom, forest, beach,
                    city, street, night, day, sunset, building, furniture
12. other        ← 剩下的
```

### 成年人向词怎么归类

`cum`、`penis`、`vagina`、`sex`、`anal`、`oral` 这些，建议**单独一类 `adult`**，不要塞进 body。

理由：这类词进词表是有用的（用户就是会用到），但混在 `body` 里会让「身体」这个分类变得不能公开看。单独一类，默认折叠，用户自己展开。

### 判完自查

- 每个类别的条数要能解释。`clothes` 应该两三千，`composition` 一两千，`other` 要是还超过三千，说明规则漏了一大块
- `other` 里随机抽 50 条看一眼，如果一半是明显能归类的，规则有问题

## 四、不要做的事

- **不要给角色名、作品名做翻译**。词表只做 tag
- **不要动 `count` 字段**。那是频次，重算会变
- **不要重新排序**。顺序是「被多少支 LoRA 用过」，动了一致性就没了
- **不要同时改 `data/wordbank-zh-curated.json` 和 `public/v2/wordbank.json`**。前者是人工校订的源，后者是构建产物；要用 `build-wordbank.mjs` 重建，不要手改产物

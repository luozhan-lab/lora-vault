## 二、P0：口径不一致，先把入口统一

### 1. 场景服装和选择器服装是两套

- 场景表里自带 217 条服装引用，**去重后是 33 个单件**：`knit sweater`、`white t-shirt`、`camisole`、`sun shirt`、`blouse`、`cardigan`、`jeans`、`hoodie`…
- 选择器只给整套（`OUTFIT_SETS` 白名单），这些单件**选不到**，但随机到场景时会出现
- 结果：你手选这套衣服、随机到那个场景却穿另一套；同一套图里不一致
- 建议：场景的 `outfits` 全部改成 `OUTFIT_SETS` 里的整套引用；确实要单件的（如浴室 `bath towel`），补进白名单并标注「场景专属」
- 影响：场景 106 条里的 `outfits` 数组，数量不变，内容换口径

### 2. 场景专属动作 64 条引用（去重 29 个）不在全局池

- `reading`、`sleeping`、`eating`、`hand in hair`、`hand on cheek`、`holding phone`、`dancing`、`praying`、`holding umbrella`、`in water`、`watering flowers`、`sitting on tatami`…
- 这些只在特定场景随机时出现，动作选择器里看不到，正常模式全局随机也抽不到
- 建议：通用动作（reading / sleeping / eating / writing / holding phone / dancing / praying / holding umbrella）补进 `EXTRA_ACTIONS_SFW`，靠已有的 `actionSceneCompatible` 限制场景；场景表只留真专属（`in water` / `watering flowers` / `sitting on tatami`）
- 影响：动作池 +8 左右，场景专属缩减

### 3. 152 条姿势词混在动作数组里

- `kneeling on bed, thighs apart, leaning back`、`sitting on desk, legs crossed, leaning back`、`lying on bed, on side, hugging knees` 这类，靠 `isPoseTag()` 的正则猜出「这是姿势」
- 现在能跑对，但加词时容易放错池；正则漏判一次，姿势就跑到动作卡里
- 建议：单独建 `EXTRA_POSES`，把这 152 条搬过去；`allActions()` 改成「动作池 + 姿势池」合并，不再靠正则猜
- 影响：不改选择器数量，只改数据结构

### 4. 光里有「夜晚」和「阴天」

- `LIGHTS` 里的 `night` 和时间里的 `night` 重复，而且「夜晚」是时间不是光线质感
- `overcast`（阴天）也是天气，不是光
- 建议：删 `night`（时间里有）；`overcast` 改 `overcast light`（阴天光）
- 影响：光 18 → 17

## 三、P1：重复和泛词

### 5. 服装泛词 5 条

| 条目 | 问题 | 建议 |
|---|---|---|
| `uniform` | 太泛，跟 `school uniform` / `sailor uniform` / `military uniform` 抢 | 删 |
| `dress` | 太泛，下面是 `sundress` / `wedding dress` / `gothic dress` 等具体款 | 删 |
| `jersey` | 太泛，且和 `volleyball uniform, jersey, …` 成套重复 | 删 |
| `swimsuit` | 跟 `school swimsuit` / `one-piece swimsuit` 并存 | 改 `one-piece swimsuit` |
| `tennis outfit`（单段） | 已有成套 `tennis outfit, pleated skirt, white socks, sneakers` | 删单段那条 |

- 影响：服装 91 → 86

### 6. 表情「笑」家族 10 条 → 6 条

现在：`smile` / `soft smile` / `gentle smile` / `shy smile` / `laughing` / `soft laugh` / `grin` / `smirk` / `disdainful smile` / `forced smile`

建议保留：`smile`、`soft smile`、`shy smile`、`laughing`、`smirk`、`forced smile`
并入：`gentle smile` → `soft smile`；`soft laugh` → `laughing`；`grin` → `smile`；`disdainful smile` → `smirk`

- 影响：SFW 表情 56 → 52

### 7. 表情「看」家族 7 条，重叠一对

`looking away` / `closed eyes` / `winking` / `wide-eyed` / `raised eyebrows` / `soft gaze` / `gentle gaze`
`soft gaze` 和 `gentle gaze` 基本同义 → 留 `gentle gaze`，删 `soft gaze`

- 影响：SFW 56 → 51（含第 6 条）

### 8. 景别特写 12 条里的重叠和泛词

| 条目 | 问题 | 建议 |
|---|---|---|
| `膝上 = thigh focus` | 和 `腿部特写 = leg focus, thighs close-up` 重叠 | 删 |
| `特写 = close-up` | 太泛，和面部/半身/局部特写抢 | 删 |
| `局部特写 = detail shot` | 太泛，不知道特什么 | 删 |

- 影响：景别 20 → 17

### 9. 角度两对重叠

- `俯视 = from above` vs `俯拍 = high angle`
- `仰视 = from below` vs `低角度 = low angle`
- 建议：留 `from above` / `from below`（底模更常见），删 `high angle` / `low angle`
- 影响：角度 13 → 11

## 四、P2：质量补强

### 10. 表情 34/141 没有支撑词

- `EXPRESSION_SUPPORT` 现在覆盖大部分情绪，但 `smile`、`blush`、`serious`、`confident` 这类最常用的反而缺
- 没有支撑词的表情，光挂一个 tag 容易被底模拉回默认脸（这是旧代码就存在的问题，不是这次引入）
- 建议：按「最常用前 20 个」补支撑词，别一次全补

### 11. 体型自带权重超过新上限

- 幼女的 `(small face:1.4)`、`(large eyes:1.4)`，萝莉的 `(5 heads tall:1.3)`
- 词路里表情已经 1.25，体型再来 1.4 会抢脸
- 建议：体型自带权重压到 1.3 以内，跨过头身比那几条保持 1.2–1.3

### 12. 动作中文名一条重复

- `单腿抬起` 同时对应 `leg lift` 和 `one leg raised`（`one leg raised` 在 `POSE_RE` 里，实际是姿势）
- 建议：`one leg raised` 改「单腿抬起·屈膝」，或者并进 `leg lift`

### 13. 成人手上 107 条抽查同义

- `hand on crotch` / `hand between legs` / `rubbing herself` / `fingering herself` 语义接近
- 建议：抽查后合并 2 条，别全删（这些在成人向是常用差异词）

## 五、建议的动手顺序

1. **P0-1 场景服装统一口径**（影响最大，也是你最常撞上的：随机场景换了衣服）
2. **P0-2 通用动作补进全局池**
3. **P0-3 姿势词独立成池**（纯数据结构，不改选项）
4. **P1-5/6/8/9 删泛词和重叠**（数量变化小，但选择器干净）
5. **P2-10 补支撑词**（要出图验证，放后面）

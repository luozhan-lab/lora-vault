# 洛栈 · LoRA-Vault 1.3.1

## 这次改了什么

- **修复：C站链接下载全部失败**。1.3.0 里下载请求头少了一个常量，搜索、下载、补信息全报「UA is not defined」；现在恢复，下载正常。
- **修复：下载框选「下载到分类 → 自动」时报「目标分类路径不合法」**。空路径被当成非法路径拒绝了，现在会自动放进「未分类」目录。

之前正常用的部分没动，覆盖安装即可。

## 怎么升级

下载 `LoRA-Vault-1.3.1-setup.exe` 直接覆盖安装，数据和设置都保留。绿色版解压后替换整个文件夹，`%APPDATA%\LoRA-Vault` 里的数据不用动。

# LoRA-Vault 1.3.1

## What's new

- **Fixed: every Civitai download failed.** A missing constant in the request header broke search, downloads and metadata filling with "UA is not defined". It is back, downloads work again.
- **Fixed: choosing "Auto" in the download category box failed** with "invalid target category path". Empty paths are now accepted and land in the "uncategorized" folder.

Nothing else changed — just install over the current version.

## Upgrading

Run `LoRA-Vault-1.3.1-setup.exe` over your current install — data and settings are kept. Portable zip users: replace the whole folder; the data in `%APPDATA%\LoRA-Vault` stays as it is.

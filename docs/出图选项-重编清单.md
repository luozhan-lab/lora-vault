## 一、一条判据

**一个选项 = 一个能直接塞进 ComfyUI、出图看得见的具体词。**

由此推出四条：

1. **同层不重复、不互相包含**：「校服」和「校服全套」只能留一个；「润滑液」和「润滑剂」只能留一个。
2. **不在错的层**：特写不该是动作，体位不该出现在单人池，阶段（抽送 / 内射）不该是动作。
3. **不跨层抢词**：手部动作不能同时躺在「姿势」和「手上」两个池里。
4. **正常池不混成人词，成人池不重复正常词**。

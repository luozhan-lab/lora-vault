# 洛栈 · LoRA-Vault 1.1.0

## 这次改了什么

- **出图区重新排过**：所有选项按「画质 → 身份 → 身体 → 衣着 → 构图 → 姿态 → 互动 → 面孔 → 环境 → 收尾」十个层次从上往下排，原来要点开的「更多细节」全部摊开。从上往下选一遍，出来就是一句完整的词。
- **选项池瘦身**：删掉同义、重复和只差时间的条目。场景 98 → 81，服装只留整套，表情 51 → 40，姿势 133 → 71，纹身、景别、角度、光线、时间也各收了一批。每个选项都能直接拿来用。
- **双人日常动作**从 12 条补到 24 条，正常模式下可选的互动不再只有几个。
- **修复**：个别情况下服装选项的负面词没有生效；有几套快速风格指向了已经删掉的条目。
- **文案统一**：卡片术语口径统一，中英文一致。
- **数据目录改成英文路径**：`%APPDATA%\LoRA-Vault`（原来在 `%APPDATA%\LoRA 库`）。第一次启动会自动把老数据复制过去，老目录保留不动，库和设置都不会丢。

## 怎么升级

下载 `LoRA-Vault-1.1.0-setup.exe` 直接覆盖安装，数据和设置都保留。用绿色版的，解压后替换整个文件夹，`%APPDATA%\LoRA 库` 里的数据不用动。

# LoRA-Vault 1.1.0

## What's new

- **Create page rebuilt.** Every option now sits in one of ten layers — quality → identity → body → outfit → framing → pose → interaction → face → scene → finish — ordered top to bottom. The old "More details" foldout is gone; everything is on the page. Pick your way down and you have one complete prompt.
- **Option pools trimmed.** Synonyms, duplicates and near-identical entries are gone. Scenes 98 → 81, outfits are full sets only, expressions 51 → 40, poses 133 → 71; tattoos, shots, angles, lighting and time were tightened too. Every remaining entry is usable as-is.
- **Duo daily actions** expanded from 12 to 24, so normal mode has more than a handful of interactions.
- **Fixed:** clothing negatives not applying in a few cases; several quick styles pointing at entries that no longer existed.
- **Copy pass.** Terminology is consistent between the Chinese and English UI.
- **Data folder moved to an English path:** `%APPDATA%\LoRA-Vault` (previously `%APPDATA%\LoRA 库`). On first launch your old data is copied over automatically; the old folder is left untouched, so nothing is lost.

## Upgrading

Run `LoRA-Vault-1.1.0-setup.exe` over your current install — data and settings are kept. Portable zip users: replace the whole folder; the data in `%APPDATA%\LoRA 库` stays as it is.

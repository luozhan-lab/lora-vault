# 洛栈 · LoRA-Vault 1.1.0

这次是出图区的大改。

- 选项按 ComfyUI 的词序排成十层：画质 → 身份 → 身体 → 衣着 → 构图 → 姿态 → 互动 → 面孔 → 环境 → 收尾。原来的「更多细节」不再折叠，全部摊开，从上往下选完就是一句词。
- 选项内容重编：删掉同义、泛词、只差时间的重复。场景 98 → 81，服装只留整套（选择器 90 → 67），表情 51 → 40，姿势 133 → 71，纹身位置 23 → 13，景别 / 角度 / 光 / 时间也各收了一批。
- 成人标记（`ADULT_TAGS`）和成人动作池分开维护，正常模式不会漏成人词，成人模式也不缺词。
- 双人日常动作从 12 补到 24 条，正常模式的「动作」不再只有 9 个。
- 修了两处旧问题：直接选服装「全裸」现在会压衣服负面；快速风格里引用了已删除服装和夜间场景的，全部改成整套 / 场景+时间。
- 卡片文案：「肉棒」改成「阴茎」。
